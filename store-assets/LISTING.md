## Description
Not every link deserves a click.

Linklight checks where a link or QR code leads before you open it, so you can spot phishing, malware and scam pages in seconds. It takes one click from your toolbar.

HOW IT WORKS
1. Click the Linklight icon, then paste a link or scan a QR code.
2. Linklight asks several trusted security sources about that destination at once.
3. You get a clear rating, Low, Medium or High Risk, with a 0–100 score and the reasons behind it.

WHY PEOPLE USE IT
• Check a link from an email, text or DM before you tap it.
• Scan a QR code with your laptop camera or upload a QR image, and see its real destination first.
• Get a plain-English verdict, not a wall of security jargon.
• Stays dependable under load. If one security source is busy, Linklight asks the others, so you still get an answer.

CHECKED AGAINST TRUSTED SOURCES
Google Safe Browsing, VirusTotal and URLhaus, the same kinds of databases security teams use.

HONEST BY DESIGN
• "Unknown" means unknown. If no report exists, Linklight says so. It never turns missing data into a green light.
• Automated checks can miss threats or flag harmless links. Low risk does not guarantee a link is safe.

PRIVATE BY DEFAULT
• No account, no sign-up, no tracking.
• Camera frames are processed on your device and are never uploaded or recorded.
• Only the link you choose to check is sent to Linklight and the security services above. Avoid checking links that contain passwords or private tokens.

Free to use. Also available as a website at https://linklightns.vercel.app

Look before you leap.

## Privacy tab answers
- Single purpose: Check whether a link or QR code destination shows signs of being unsafe before the user opens it.
- Host permission justification (linklightns.vercel.app): Sends the link the user chooses to check to the Linklight service and receives the risk result.
- storage permission justification: Stores the user's own settings locally in the browser.
- Remote code: No. All code is bundled in the extension.
- Data collected: Website content (the URL the user submits). It is used only to return a result, and is not sold or used for unrelated purposes.
